# AGENTS.md for motto-appraisal-site

## Overview
Production-ready website for Motto Appraisal Service, a licensed DFW real estate appraisal firm. Built with HTML5, vanilla CSS (custom properties), and vanilla JavaScript (~6KB). Multi-page site with home, services, about, newsletter, contact, order forms, blog, and service-area pages.

## Development

### Setup
Open index.html in a browser or use a local server:
```bash
npx serve .
```

### Test
Manual visual verification in browser.

### Lint
```bash
npx prettier --check "**/*.{html,css,js}"
```

## Deployment
Deployed via static hosting (Cloudflare Pages or similar).
